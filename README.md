# 🚰 Stemaks Plomberie Bruxelles (Woluwe-Saint-Lambert)

Site web officiel de **Stemaks Plomberie**, entreprise agréée de plomberie, débouchage et dépannage d'urgence 24h/24 & 7j/7 basée à **Woluwe-Saint-Lambert (1200 Bruxelles)**.

Développé avec [Astro](https://astro.build) pour des performances statiques ultra-rapides, une optimisation SEO locale de premier ordre (Schema.org LocalBusiness & Plumber) et un design moderne responsive.

---

## 📄 Pages Incluses

- **Accueil (`/`)** : Hero avec badge d'urgence live, statistiques de confiance, simulateur de prix interactif, aperçu des prestations, avis clients vérifiés et FAQ.
- **Services (`/services`)** : Détail complet des prestations (débouchage haute pression, recherche de fuite sans casse, boiler/chauffe-eau, rénovation sanitaire clé en main, robinetterie, détartrage/adoucisseurs), méthode en 4 étapes et engagements garantis.
- **Zones d'Intervention (`/locations`)** : Focus local sur Woluwe-Saint-Lambert (Avenue Georges Henri, Roodebeek, Tomberg, Marcel Thiry) et couverture des 19 communes de Bruxelles avec outil de recherche dynamique et délais d'intervention en direct.
- **À Propos (`/about`)** : Histoire de l'artisanat Stemaks, équipe, matériel technologique d'inspection, agréments SPF Économie, garantie décennale et assurance RC Pro 2 500 000 €.
- **Contact & Devis (`/contact`)** : Formulaire de devis gratuit avec validation interactive et pré-remplissage automatique, coordonnées d'urgence 24/7 et informations d'accès.

---

## 🛠️ Stack Technique

- **Framework** : [Astro 5](https://astro.build)
- **Styling** : Vanilla CSS moderne avec design system sur mesure, variables CSS, typographies Google Fonts (*Outfit* & *Plus Jakarta Sans*) et effets glassmorphism.
- **SEO & Référencement Local** :
  - Métadonnées OpenGraph & Twitter Cards
  - Schema.org JSON-LD `Plumber` / `LocalBusiness` avec géolocalisation Woluwe-Saint-Lambert (50.8427, 4.4172)
  - Données structurées pour les services et les avis
  - Balises canoniques et multilinguisme francophone (`lang="fr"`, `fr_BE`)
- **Déploiement** : Vercel / GitHub

## 🚀 Démarrage Local

```bash
# Installation des dépendances
npm install

# Démarrer le serveur de développement local
npm run dev

# Compiler pour la production
npm run build

# Prévisualiser la version de production
npm run preview
```
